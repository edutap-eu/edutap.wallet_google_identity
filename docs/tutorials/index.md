# Tutorials

A tutorial teaches you the package by building something with it.

There is no tutorial yet, because there is nothing to build yet.
Issuance is not implemented, so any lesson written today would teach a workflow that does not run.

When issuance works, the first tutorial will walk you through issuing a student credential into a test wallet, from the Credential Offer to the credential on the device.

Until then, start with {doc}`../how-to/install-for-development` to get the package running, and with {doc}`../explanation/why-openid4vci` to understand what it will do.
